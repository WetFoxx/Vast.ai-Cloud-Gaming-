# VastGame 0.5.21 beta

This release improves how VastGame saves and restores games, mods, and settings on Google Drive between Vast.ai sessions.

- **Safer cloud saves.** VastGame verifies an upload before it replaces the previous backup. If it can’t confirm the final save, it keeps the rental running and lets you retry from the app.
- **Recovery after an interrupted upload.** When the same machine retries with its local upload record intact, VastGame can resolve an uncertain publication or automatically move unreferenced parts from its own interrupted upload to the Google Drive trash.
- **Less work for small changes.** The sync engine reads fewer unchanged files, sends fewer storage requests, and preserves earlier changes when it updates an incremental archive.
- **More resilient desktop updates.** The macOS and Windows updaters retain the previous installation for rollback if the updated app fails to start.

Desktop downloads are available for Apple Silicon Macs and 64-bit Windows. Streaming still uses Tailscale and Moonlight.
