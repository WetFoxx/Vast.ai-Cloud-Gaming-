# VastGame 0.5.27 — Session Lifecycle Hardening & Emergency Termination Reliability

This release strengthens paid instance safety, crash recovery, and session shutdown reliability across Windows and macOS while preserving all Steam authentication improvements from 0.5.26.

**What's fixed and improved:**

- **Independent Emergency Instance Deletion:** Emergency deletion ("Delete without uploading") is no longer blocked or hidden when a launch or stop operation is active or stuck, and no longer depends on Moonlight, Sunshine, Tailscale, Steam, or Google Drive availability. After explicit double confirmation, VastGame aborts active background operations and terminates the confirmed instance directly via the Vast.ai API.
- **Persistent Rental Journal & Crash Recovery:** Each rental attempt is recorded atomically before contacting Vast.ai with a unique operation label (`vastgame:<run_id>`). If a network response is lost, the app closes unexpectedly, or cancellation occurs mid-request, VastGame reconciles the exact rental on restart without ever guessing or touching unrelated Vast.ai instances.
- **Honest Deletion Verification & Billing Warnings:** VastGame now verifies actual instance disappearance via Vast.ai before reporting deletion as complete. If the API response is lost or unreachable, the app displays a persistent warning (surviving restarts and offline mode) that billing may continue, along with a direct link to the Vast.ai Instances console.
- **Safer Steam Shutdown & Reliable Session Finishing:** Improved remote `steam_off()` handling in `wolf-setup.sh` so that if Steam ignores `-shutdown` (for example during client updates), it escalates to a graceful `SIGTERM` and waits for active game processes (`reaper`) to settle before archiving — without ever using unsafe `SIGKILL` or deleting instances when cloud upload verification fails.
- **Non-Blocking UI Reconciliation:** Background rental reconciliation runs asynchronously in a single-flight worker so the main UI stays responsive during slow or offline API states, and visually dismissing a warning banner does not disable background safety checks.
- **Expanded Diagnostics & UI Controls:** Added emergency termination controls directly on the progress and finish-hold screens, expanded diagnostic error reporting (`core.delete_uncertain`, `core.emergency_aborted`, `core.instance_unconfirmed`), and updated RU, EN, and ES localizations.

**Compatibility:**
- Windows 10/11 (x64)
- macOS (Apple Silicon)

**Note:** Live interactive Moonlight video decoding and interactive Steam sign-in were not automated in headless release validation and should be spot-checked if needed.

Thank you for using VastGame! If you encounter any issues, please report them on GitHub.
