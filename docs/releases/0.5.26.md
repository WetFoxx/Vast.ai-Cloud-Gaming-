# VastGame 0.5.26 — Steam Authentication & Account Management Fixes

This update focuses on improving Steam authentication reliability and account management across Windows and macOS.

**What's fixed and improved:**

- Fixed an issue where Steam authentication could fail to complete after a successful sign-in.
- Improved compatibility with Steam's login process on Windows (WebView2) and macOS (WebKit).
- Fixed Steam account reauthorization and improved handling of expired sessions.
- Improved Steam account removal and reconnection.
- Fixed account identification during reauthorization to prevent linking the wrong Steam account.
- Improved Steam library refresh so newly added games can appear after updating the library.

**Compatibility:**
- Windows 10/11
- macOS

Thank you for using VastGame! If you encounter any issues, please report them on GitHub.
