## VastGame 0.5.23 beta

- Machine search starts with a smaller list to reduce Vast.ai search quota usage. Use **Show more** for a wider selection.
- Filters, sorting, and pagination use the loaded list. Reopening the same search briefly reuses results, and simultaneous identical searches share one request.
- If Vast.ai reports that the daily search quota is exhausted, VastGame stops retrying and tells you when to try again.
