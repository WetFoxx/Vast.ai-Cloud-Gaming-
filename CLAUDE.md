## Что строим

Консольную утилиту на Python (готова, команды ниже), а поверх неё — настольное приложение на **pywebview** (Python + интерфейс веб-страницей в окне; решение 2026-09-23 вместо Tauri, чтобы весь проект был на одном языке). Команды утилиты:

- `balance` — баланс Vast (`balance.py`, готово).
- `offers` — таблица подходящих машин: GPU, цена в час, страна, надёжность, трафик (`offers.py`, готово; поиск — общий `market.py`).
- `play` (`play.py`, готово) — без ID подбирает машину сам (`market.search`: все страны, RTX/GTX, KVM, надёжность от 0.97, сортировка по полной цене часа; показывает пятёрку со странами — задержка зависит от расстояния, Enter — №1); с ID — конкретную. Хосты, которые не смогли запустить машину, — в чёрный список `~/Library/Application Support/vastgame/bad_hosts.json` (по `machine_id`). Арендовать выбранную машину по шаблону, дождаться готовности, показать адрес для Moonlight. Выключатель «загружать игры из облака» — передаётся при аренде как `SYNC_STEAM_GAMES=0/1` (скрипт читает его только при старте инстанса, поэтому действует со следующей аренды).
- `stop` — выгрузить всё на инстансе, дождаться подтверждения и только потом удалить инстанс (`stop.py`, готово).
- `migrate` (`migrate.py`) — перенос архивов из старой папки в папку приложения (разовый, при переходе на свой OAuth-клиент).
- `games` (`games.py`, готово) — игры и сохранения в облаке с размерами — прямо с Drive через rclone на Mac, машина не нужна; названия сохранений (`pfx--<appid>`) — из публичного API магазина Steam. `games rm <название>` — в корзину Drive (30 дней): при работающей машине через `wolf forget` по SSH (иначе wolf выгрузит заново), без машины — `rclone deletefile --drive-use-trash=true`. Служебные архивы не удаляются.
- `info` (`info.py`) — адреса работающей машины: Moonlight (имя MagicDNS), кабинет Sunshine `https://<узел>:47990`, статус `:8099`; те же адреса печатает `play` в конце.
- Всё запускается одной командой `vastgame <команда>` (`vastgame.py` + `bin/vastgame`, ссылка в `/opt/homebrew/bin`). Общий код: `vastapi.py` (Vast), `wolfnode.py` (Tailscale, SSH, /json), `drive.py` (Drive через rclone: настройки в переменных окружения, личный конфиг rclone не трогается).
- `setup` — позже: вход в Google, ключ Tailscale, сохранение секретов в Keychain.

Это «агент»: восстанавливает из Google Drive сессию Steam, сохранения и сетевую личность, выгружает изменения обратно, управляет разрешением экрана. **Читай его, когда нужно понять, что происходит на инстансе.**
- Vast: образ `docker.io/vastai/kvm:ubuntu_desktop_22.04` (нужен именно KVM, не контейнер). Шаблон для утилиты — приватный `vastgame`: его создаёт/обновляет мастер (`vastgame setup`, шаг «Шаблон»; содержимое — константы в `setup.py`: образ, порты с `41641/udp`, служебные переменные портала Vast, загрузчик, фильтры, настройки RES/SYNC_STEAM_GAMES/STEAM_LANG и `recommended_disk_space`). Ключей в нём нет. `vastapi.my_template()` ищет его по имени (hash_id меняется при каждом сохранении). Создание — `POST template/`, изменение — `PUT template/` с `hash_id` в теле, удаление — `DELETE template/` `{"hash_id"}` (как в CLI). `extra_filters` — объектом. Старые шаблоны Алексея: `WETFOX CLOUD GAME` (порт 741641, загрузчик на ревизии 787acea = v3.7) и `WETFOX CLOUD GAME TEST` (ключи внутри, загрузчик без ревизии). Прежний `WETFOX CLOUD GAME`: `hash_id=49faada2e6e7fe3e15bef0ea1999420a`. При сохранении шаблона на сайте меняется `hash_id` — искать через `GET template/` с `select_filters={"name": {"eq": ...}}`. Скрипт скачивается загрузчиком из gist, ссылка закреплена на ревизии.
- Секреты на инстанс попадают из Environment Variables аккаунта Vast (Settings → Environment Variables; через API — `GET secrets/`, выводить только имена). **Обязателен `RCLONE_REFRESH_TOKEN`**: без него нет Drive → не восстанавливается `identity` → Tailscale остаётся `Logged out`. `TAILSCALE_AUTHKEY` нужен только при первом входе: дальше состояние узла приезжает из Drive в `identity`; с ключом при потере `identity` появится новый узел `vastai-gaming-N`, без ключа узел не поднимется. Раньше Алексей вписывал ключи в шаблон вручную при аренде — утилита так не умеет, поэтому ключи должны быть в аккаунте. Прочие: необязательные — `RCLONE_CLIENT_ID`, `RCLONE_CLIENT_SECRET`, `ZT_NETWORK_ID`, `SYNC_STEAM_GAMES`, `STEAM_LANG`, `TAILSCALE_SSH` и другие (полный список — в `wolf-setup.sh`).
- Сеть: Tailscale, узел `vastai-gaming`, MagicDNS. Полное имя — `vastai-gaming.<tailnet>.ts.net`. Мой Mac тоже в этой сети; утилита берёт имя и IP из `tailscale status --json` (узел с HostName `vastai-gaming`, который Online). **Moonlight подключают по имени, не по IP.**
- Tailscale SSH включён: с Mac можно выполнить команду на инстансе через `ssh root@<узел>`. **Это первый способ управлять инстансом из утилиты** — без нового API на инстансе.
- Статус инстанса: `http://<узел>:8099/json` — только через Tailscale. Список архивов и их состояние: `ok`, `up`, `down`, `wait`, `err`.
- Команды на инстансе: `sudo wolf shutdown` (закрыть Steam и выгрузить всё), `state`, `games`, `restore ИМЯ`, `push ИМЯ` (`NOW=1` — сразу), `forget ИМЯ` (убрать архив игры из облака).
- Google Drive: папка `vastai-cloud-games`. Архивы: `identity`, `steam-state`, `steam-client`, `steam-cache`, `pfx--<appid>` (сохранения), `game--<папка>` (игры не из Steam), `sgame--<папка>` (игры Steam).

## Vast API

Проверено по документации (docs.vast.ai/api-reference) и на живом API. Общий код запросов — `vastapi.py`.

- База: `https://console.vast.ai/api/v0/`, авторизация заголовком `Authorization: Bearer <ключ>`.
- `GET users/current/` — данные аккаунта. Деньги на счету — поле `credit` (сверено с консолью; `balance` — другое, обычно 0).
- ~~`GET instances/`~~ — отключён (HTTP 410). Список инстансов — `GET https://console.vast.ai/api/v1/instances/` с параметрами `select_filters`, `order_by`, `limit` (JSON в query), по страницам через `next_token` → `after_token` (`vastapi.list_instances`).
- `GET instances/<id>/?owner=me` — один инстанс в `{"instances": {...}}` (`null`, если нет). Поле `actual_status`: ждём `running`; из `exited`/`offline`/`unknown` до `running` уже не дойдёт.
- `DELETE instances/<id>/` (тело `{}`) — удаление, ответ `{"success": ...}`.
- Ошибки: объяснение в поле `msg`.
- `POST bundles/` — поиск предложений; фильтры в JSON вида `{"gpu_name": {"eq": "RTX 4090"}, "rentable": {"eq": true}, "num_gpus": {"eq": 1}, "order": [["dph_total", "asc"]], "type": "ondemand", "limit": 20}`. Проверено на живом API:
  - `gpu_name` — с пробелом: `"RTX 4090"`. Вариант из документации `RTX_4090` находит 0 машин.
  - `type`: работают и `"ondemand"`, и `"on-demand"`.
  - KVM: `"vms_enabled": {"eq": true}` — из ~700 машин с 1 GPU подходят ~70.
  - `dph_total` зависит от `"allocated_storage": <ГБ>` в запросе: без него цена считается под диск 8 ГБ и занижена.
  - Трафик: `inet_up_cost` (исходящий — стрим) и `inet_down_cost` (входящий — скачивание из Drive), в $ за ГБ. У большинства хостов ~0.003–0.004 $/ГБ, у единиц — практически 0.
  - Прочие поля: `reliability` (0–1), `disk_space` (ГБ свободно), `geolocation` (`"Quebec, CA"`, бывает `", CN"`), `storage_cost` ($/ГБ/месяц).
- `PUT asks/<offer_id>/` — аренда; в ответе `new_contract` — это id нового инстанса. Тело (как в официальном CLI): `{"client_id": "me", "template_hash_id": "...", "disk": 100, "label": "vastgame", "env": {"SYNC_STEAM_GAMES": "1"}}` — `env` словарём, сливается с env шаблона. Переменные из Environment Variables аккаунта попадают в любой инстанс; в VM env пишется в `/etc/environment`.
- Поиск машины по ID: `"ask_contract_id": {"eq": ID}`. Фильтр `"id"` молча находит 0.
- Переменные аккаунта: `GET secrets/` → `{"secrets": {имя: "********"}}` — значения замаскированы, сверять можно только имена. `POST secrets/` `{"key", "value"}` — создать, `PUT` — заменить, `DELETE` `{"key"}` — удалить (как в CLI). Запись — `setup.py vast`.
- Бывают ключи с ограниченными правами (например, без доступа к биллингу) — перейти на такой, когда определимся с нужными правами.

Уточнить в документации перед использованием, **не угадывать**:

- (пока всё нужное проверено)

**Свой OAuth-клиент Google (сделано 2026-09-23).** Общий client_id rclone «is being retired and will stop working during 2026». Проект Google Cloud `vastgame` (аккаунт Алексея), клиент «Desktop app», scope `drive.file` (non-sensitive — тяжёлая проверка не нужна), статус In production. Для публикации External-приложения консоль требует home page, privacy policy и authorized domain (не помечены обязательными): `https://github.com/WetFoxx/Vast.ai-Cloud-Gaming-`, `.../blob/main/PRIVACY.md`, `github.com`. Логотип не загружать — запускает проверку.
- Keychain: `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`, `RCLONE_REFRESH_TOKEN` (через клиент, `RCLONE_TOKEN_SCOPE=drive.file`), `RCLONE_REFRESH_TOKEN_OLD` (общий клиент rclone, полный доступ — только для `migrate`). В аккаунт Vast уходят `RCLONE_CLIENT_ID`, `RCLONE_CLIENT_SECRET`, `RCLONE_REFRESH_TOKEN`.
- `rclone authorize drive <blob>`: blob — base64 **без `=`** от JSON `{"client_id","client_secret","scope"}`.
- `wolf-setup.sh` менять не нужно: `scope = drive` в его rclone.conf не мешает — права задаёт токен (проверено).
- С `drive.file` приложение видит только своё. Старые архивы переносит `vastgame migrate` (старый токен читает, новый пишет, сверка MD5). 2026-09-23 перенесено 13 файлов из `commission download/vastai-cloud-games` — это резервная копия, Алексей удалит сам.
- **Грабли:** на Drive бывают папки с одинаковыми именами. Удалять/искать папки только по ID, никогда по пути: `migrate` так унёс в корзину только что перенесённую папку (восстановлена по ID). `drive.set_trashed(id)` — Drive API по ID, но только для созданного приложением; созданное общим клиентом rclone удаляет сам Алексей на сайте.
- Перенос идёт через домашний интернет (~2.5 МБ/с у Алексея). Для больших библиотек — переносить на арендованной машине.
- Для новых пользователей: зашить Client ID/secret приложения в код (для Desktop app секрет не секретный), шаг «OAuth-клиент» в мастере убрать, оставить скрытую возможность своего клиента.

## Приложение (pywebview) — что должно быть

- **Первая настройка (мастер):** проверка и установка Moonlight, Tailscale, rclone (кнопка «Установить» — Homebrew на Mac: `moonlight`, `tailscale-app`, `rclone`; `winget` на Windows — ID проверить; и ссылка «Скачать с сайта»; установка только после подтверждения); ключ Vast; вход в Google; ключ Tailscale; настройки шаблона; перенос архивов.
- **Главный экран:** баланс и на сколько часов хватит; состояние машины; «Играть» / «Закончить».
- **Выбор машины:** таблица и автовыбор (все страны, RTX/GTX, надёжность от 0.97), чёрный список хостов.
- **Запуск:** этапы с прогрессом (Vast → Tailscale → каждый архив); имя для Moonlight, ссылка на кабинет Sunshine; при ошибке хоста — удалить и взять другую.
- **Во время игры:** статус синхронизации, время сессии и её стоимость.
- **Остановка:** выгрузка с проверкой → удаление после подтверждения; не подтвердилась — не удалять и объяснить; ссылка подтверждения Tailscale SSH. **Аварийное «Удалить без выгрузки»** — двойное подтверждение.
- **Игры в облаке:** список, удаление в корзину, выключатель загрузки игр (нужна правка `wolf-setup.sh`).
- **Значок в строке меню / трее** со статусом: ⚪ машины нет · 🟡 запускается (этап в меню) · 🟢 готова к игре (всё восстановлено) · 🔵 синхронизация (выгрузка во время игры) · 🟠 выключается · 🔴 ошибка. Меню: открыть приложение, открыть Moonlight, закончить игру.
- **Уведомления:** машина готова; сохранения выгружены; **баланс ниже $1**.
- **Открыть Moonlight:** `Moonlight stream <узел> "<приложение Sunshine>"` (проверено: CLI Moonlight 6.1 умеет `stream`, `list`, `pair`, `quit`; есть `--resolution`, `--fps`, `--bitrate`, `--display-mode`). Имя приложения Sunshine уточнить на живой машине (`Moonlight list <узел>`).
- **История сессий и траты:** каждая сессия (когда, машина, длительность, цена) пишется локально; реальные суммы — из счетов Vast, если API позволяет (проверить).
- **Не делаем:** автовыключение.
- Порядок работы: 1) ядро — `play`/`stop` как функции с событиями, терминал поверх того же ядра; 2) окно-скелет: баланс и статус; 3) «Играть»; 4) «Закончить» и аварийное удаление; 5) игры; 6) мастер; 7) история и траты; 8) значок, уведомления, Moonlight (проверить совместимость pywebview и значка в главном потоке macOS); 9) сборка .app, затем Windows.

- Только KVM: в контейнере нельзя управлять X-сервером и EDID, картинку не получить.
- Ставку за трафик задаёт хост. Стрим — 10–20 ГБ в час. Строгий фильтр «трафик $0» оставляет 1–2 машины, поэтому `offers` показывает цену трафика и сортирует по полной цене.
- Нерешённое: в прошлых счетах (Billing → Charges) есть только GPU и Storage, строк за трафик нет, хотя API показывает у тех хостов ненулевую цену. После следующей аренды сверить счёт.
- Документация Vast местами врёт (пример — `RTX_4090`): поля и значения проверять пробным запросом, который не стоит денег.
- `wolf shutdown` всегда завершается с кодом 0, даже если выгрузка упала, — проверять по `/json`. Записи `err` в `/json` живут до перезагрузки: учитывать только записи с `ts` новее момента запуска shutdown. Сам shutdown ждёт конца выгрузки — нужен большой таймаут SSH. `steam-cache` при shutdown пропускается, если Steam не закрылся за 60 с.
- Инстанс удалять, а не останавливать: остановленный продолжает платить за диск.
- Одновременно работает только один инстанс: у них общие архивы и общая личность Tailscale.
- Свой OAuth-клиент Google в статусе Testing выдаёт токены на 7 дней — только In production.
- Для публичного приложения полный scope `drive` относится к ограниченным (нужна проверка Google). План — `drive.file`: приложение видит только файлы, которые создало само. Старые архивы, созданные через клиент rclone, при этом не будут видны — чистый старт.
