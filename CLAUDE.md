## Секреты — строгие правила

- Ключи лежат вне папки проекта: `~/.vast_api_key` — API-ключ Vast. Позже переедут в Keychain macOS.
- **Никогда не читай, не выводи и не копируй файлы с ключами и токенами.** Код может читать ключ, ты — нет. Не печатай ответы API целиком, если в них могут быть секреты: выводи только нужные поля.
- Ключи никогда не попадают в код, в git и в логи. В `.gitignore`: `.venv/`, `__pycache__/`, `.env`, `*.key`.
- API-ключ Vast по умолчанию полный: им можно арендовать машины и тратить деньги. **Любое действие, которое стоит денег (аренда), — только после моего явного подтверждения в этот момент.** Удаление инстанса — тоже.

## Что строим

Консольную утилиту на Python (готова, команды ниже), а поверх неё — настольное приложение на **pywebview** (Python + интерфейс веб-страницей в окне; решение 2026-09-23 вместо Tauri, чтобы весь проект был на одном языке). Команды утилиты:

- `balance` — баланс Vast (`balance.py`, готово).
- `offers` — таблица подходящих машин: GPU, цена в час, страна, надёжность, трафик (`offers.py`, готово; поиск — общий `market.py`).
- `play` (`play.py`, готово) — без ID подбирает машину сам (`market.search`: все страны, RTX/GTX, KVM, надёжность от 0.97, сортировка по полной цене часа; показывает пятёрку со странами — задержка зависит от расстояния, Enter — №1); с ID — конкретную. Хосты, которые не смогли запустить машину, — в `~/Library/Application Support/vastgame/bad_hosts.json` (по `machine_id`). **Решено 2026-09-24: не прятать, а помечать** («может не запуститься», `o["_failed"]`; сбой бывает временным); пометка снимается, когда машина на хосте дошла до `running` (`market.clear_bad` в `core.wait_ready`). Арендовать выбранную машину по шаблону, дождаться готовности, показать адрес для Moonlight. Выключатель «загружать игры из облака» — передаётся при аренде как `SYNC_STEAM_GAMES=0/1` (скрипт читает его только при старте инстанса, поэтому действует со следующей аренды).
- `stop` — выгрузить всё на инстансе, дождаться подтверждения и только потом удалить инстанс (`stop.py`, готово).
- `migrate` (`migrate.py`) — перенос архивов из старой папки в папку приложения (разовый, при переходе на свой OAuth-клиент).
- `games` (`games.py`, готово) — игры и сохранения в облаке с размерами — прямо с Drive через rclone на Mac, машина не нужна; названия сохранений (`pfx--<appid>`) — из публичного API магазина Steam. `games rm <название>` — в корзину Drive (30 дней): при работающей машине через `wolf forget` по SSH (иначе wolf выгрузит заново), без машины — `rclone deletefile --drive-use-trash=true`. Служебные архивы не удаляются.
- `info` (`info.py`) — адреса работающей машины: Moonlight (имя MagicDNS), кабинет Sunshine `https://<узел>:47990`, статус `:8099`; те же адреса печатает `play` в конце.
- **Ядро — `core.py`** (шаг 1 приложения, готов): `play`/`stop` как функции без печати и `input()`; общение через объект `ui` (`say`, `stage`, `archive`, `confirm`, `tailscale`). Этапы `stage`: `vast` → `tailscale` → `restore` → `ready`; `shutdown` → `verify` → `deleted` — по ним будет меняться значок. Терминал — `cliui.ConsoleUI`; `play.py`/`stop.py` — тонкие обёртки. Ошибки — `vastapi.VastgameError` (подвид `SystemExit`: в терминале = sys.exit; окно ловит явно, `except Exception` её НЕ ловит). Вывод `wolf shutdown` читается параллельно (иначе переполнение канала и взаимная блокировка).

## Vast API

Проверено по документации (docs.vast.ai/api-reference) и на живом API. Общий код запросов — `vastapi.py`.

- База: `https://console.vast.ai/api/v0/`, авторизация заголовком `Authorization: Bearer <ключ>`.
- `GET users/current/` — данные аккаунта. Деньги на счету — поле `credit` (сверено с консолью; `balance` — другое, обычно 0).
- ~~`GET instances/`~~ — отключён (HTTP 410). Список инстансов — `GET https://console.vast.ai/api/v1/instances/` с параметрами `select_filters`, `order_by`, `limit` (JSON в query), по страницам через `next_token` → `after_token` (`vastapi.list_instances`).
- `GET instances/<id>/?owner=me` — один инстанс в `{"instances": {...}}` (`null`, если нет). Поле `actual_status`: ждём `running`; из `exited`/`offline`/`unknown` до `running` уже не дойдёт.
- `DELETE instances/<id>/` (тело `{}`) — удаление, ответ `{"success": ...}`.
- Ошибки: объяснение в поле `msg`.
- `POST bundles/` — поиск предложений; фильтры в JSON вида `{"gpu_name": {"eq": "RTX 4090"}, "rentable": {"eq": true}, "num_gpus": {"eq": 1}, "order": [["dph_total", "asc"]], "type": "ondemand", "limit": 20}`. Проверено на живом API:
  - `gpu_name` — с пробелом: `"RTX 4090"`. Вариант из документации `RTX_4090` находит 0 машин.
  - `type`: работают и `"ondemand"`, и `"on-demand"`.
  - KVM: `"vms_enabled": {"eq": true}` — из ~700 машин с 1 GPU подходят ~70.
  - `dph_total` зависит от `"allocated_storage": <ГБ>` в запросе: без него цена считается под диск 8 ГБ и занижена.
  - Трафик: `inet_up_cost` (исходящий — стрим) и `inet_down_cost` (входящий — скачивание из Drive), в $ за ГБ. У большинства хостов ~0.003–0.004 $/ГБ, у единиц — практически 0.
  - Прочие поля: `reliability` (0–1), `disk_space` (ГБ свободно), `geolocation` (`"Quebec, CA"`, бывает `", CN"`), `storage_cost` ($/ГБ/месяц).
- `PUT asks/<offer_id>/` — аренда; в ответе `new_contract` — это id нового инстанса. Тело (как в официальном CLI): `{"client_id": "me", "template_hash_id": "...", "disk": 100, "label": "vastgame", "env": {"SYNC_STEAM_GAMES": "1"}}` — `env` словарём, сливается с env шаблона. Переменные из Environment Variables аккаунта попадают в любой инстанс; в VM env пишется в `/etc/environment`.
- Поиск машины по ID: `"ask_contract_id": {"eq": ID}`. Фильтр `"id"` молча находит 0.
- Переменные аккаунта: `GET secrets/` → `{"secrets": {имя: "********"}}` — значения замаскированы, сверять можно только имена. `POST secrets/` `{"key", "value"}` — создать, `PUT` — заменить, `DELETE` `{"key"}` — удалить (как в CLI). Запись — `setup.py vast`.
- Бывают ключи с ограниченными правами (например, без доступа к биллингу) — перейти на такой, когда определимся с нужными правами.
